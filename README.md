# 🚀 ServiQ - Smart Complaint Management System

A modern Django-based Complaint Management System with authentication, complaint tracking, admin dashboard, responsive UI, dark mode, and complaint status management.

## ✨ Features
- User Authentication
- Complaint Management
- Status Tracking
- Admin Panel
- Responsive UI
- Dark Mode
- Search & Filters

## 🛠️ Tech Stack
Python • Django • Bootstrap • SQLite • HTML • CSS • JavaScript
